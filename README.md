# Kali i3 setup

Personal Kali desktop configuration based on the i3 setup from
[xct/kali-clean](https://github.com/xct/kali-clean), with the configs currently
used on my machine.

## Included

- i3 keybindings, gaps, startup commands, and i3blocks status bar
- Rofi application launcher
- Minimal Picom configuration using XRender, with animations and visual effects disabled for responsiveness in VMware
- Kitty terminal settings adapted from my end4-based `dots-chjwoo` config
- Alacritty terminal settings
- Wallpaper and the VMware clipboard helper

## Install

Clone this repository, then run:

```sh
./install.sh --install-deps
```

The installer installs missing Kali/Debian packages used by the configuration,
then links the included files into your home directory. Use `./install.sh`
without flags to review and accept or skip missing packages interactively; use
`./install.sh --no-deps` to only link the dotfiles. If a target already exists,
the installer moves it into `~/.local/share/kali-chjwoo-backup/<timestamp>/`
first. Log out and choose i3 from the login screen, or restart i3 after
installing.

Picom uses a minimal XRender configuration because compositing adds noticeable
overhead in this VMware guest. The installer includes `open-vm-tools-desktop`
for the VMware clipboard helper.

## Wallpaper

Press `Super+Shift+W` to choose an image from `~/.wallpaper`; the selection is
applied immediately and saved for the next i3 start. Add more PNG, JPG, WebP,
BMP, or GIF files to that directory to make them available in the picker.

The Kitty setup uses a local static color fallback because the original theme
is generated by Quickshell. Install JetBrains Mono Nerd Font separately for the
intended font and status-bar clock glyph; the installer installs the regular
JetBrains Mono family as a fallback. Kitty uses the default login shell.
