# Kali i3 setup

Personal Kali desktop configuration based on the i3 setup from
[xct/kali-clean](https://github.com/xct/kali-clean), with the configs currently
used on my machine.

## Included

- i3 keybindings, gaps, startup commands, and i3blocks status bar
- Rofi application launcher
- Minimal Picom configuration using XRender, with animations and visual effects disabled for responsiveness in VMware
- Kitty terminal settings adapted from my end4-based `dots-chjwoo` config
- Alacritty terminal settings
- Wallpaper and the VMware clipboard helper

## Install

Clone this repository as `~/kali-chjwoo`, then run:

```sh
./install.sh
```

The installer links the included files into your home directory. If a target
already exists, it moves it into
`~/.local/share/kali-chjwoo-backup/<timestamp>/` first. Log out and choose i3
from the login screen, or reload i3 with `Super+Shift+C` after installing.

Install Picom with `sudo apt install picom` before starting i3. The compositor
is configured with minimal effects because it adds noticeable overhead in this
VMware guest. The VMware clipboard helper only applies when Kali runs in a
VMware guest.

The Kitty setup uses a local static color fallback because the original theme
is generated by Quickshell. It uses Kitty's default login shell; change
`font_family` in `.config/kitty/kitty.conf` if JetBrains Mono Nerd Font is not
installed on the target system.
